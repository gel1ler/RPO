Лабораторная работа №2.
Задание. Разработать REST API сервера авторизации платежей транспортными
картами.
1. Общие требования
1.1 Язык программирования GO Lang
1.2 База данных SQLITE3
1.3 REST API должен запускаться из Docker контейнера
1.4 Доступ к API следует сделать через установленный в контейнере веб
сервер Nginх по протоколу HTTPS. https://localhost:8888/api/v1 . Создать
необходимые ключи и сертификаты, настроить протокол TLS.
2. База данных
2.1 Таблица терминалов, содержащая серийный номер терминала, адрес
установки, название, и пр.
2.2 Таблица транспортных карт MIFARE, содержащая номер карты, сумму на
карте, флаг блокировки, имя владельца, и пр.
2.3 Таблица транзакций, содержащая сумму транзакции, ссылку на карту,
дату и время, ссылку на терминал
2.4 Таблица ключей, связанная отношением один ко многим с таблицей
карт. Один ключ для нескольких карт.
2.5 Таблица пользователей, содержащая логин имя и пароль, а также флаг
администратор/пользователь. Пользователь не может редактировать
данные других пользователей, а также редактировать таблицу ключей.
2.6 Добавить эту систему миграции БД. https://github.com/pressly/goose
3. REST. Авторизация пользователя.
3.1 Следует сделать вход по паролю и авторизацию с помощью JWT
4. REST. CRUD API
4.1 Сделать API для редактирования всех таблиц базы данных
5. REST API терминала
5.1 Функция авторизации платежной транзакции. Сервер проверяет номер
карты, и сумму и транзакции и возвращает терминалу результат
авторизации.
5.2 Функция загрузки ключей. Передает на терминал все имеющиеся ключи
для расшифровки данных на картах.
6. Разработать страницу с документацией SWAGGER, которая так же должна
быть доступна из Docker контейнера. https://localhost:8888/api/v1/swagger
7. REST API и Nginx должны быть собраны в одном образе с помощью
инкрементной сборки Docker.
